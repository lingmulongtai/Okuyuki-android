# インストールと最初の接続

## 用意するもの
- Android 16のGalaxy（仕様書の対象はS25 Ultra）と、更新済みのQuest 3／3S。
- 両方を接続する同じWi-Fi、またはGalaxyのテザリング。
- Samsungギャラリーの3D写真。通常の写真は3D一覧に表示されません。

## APKを入れる
各リポジトリのReleasesで、同じバージョンのAPKをダウンロードしてください。

AndroidスマホではAndroid側のAPKを開き、そのダウンロード元からのインストールを許可してインストールします。
Questでは開発者モードとUSBデバッグを有効にしてUSB接続し、ADBまたはMeta Quest Developer HubのAPKインストール機能を使用します。
ADBの場合、接続された端末のシリアルを `adb devices` で確認してから実行してください。

```sh
adb -s PHONE_SERIAL install -r Okuyuki-android-v0.1.0-alpha.1.apk
adb -s QUEST_SERIAL install -r Okuyuki-quest-v0.1.0-alpha.1.apk
```

Questのアプリライブラリーでは「提供元不明」からOkuyuki Questを開きます。
両APKは同じ配布用証明書で署名されます。別の証明書で署名した開発版から切り替える場合、Androidは更新を拒否します。既存の接続登録を失うアンインストールを行う前に確認してください。

## 接続する
1. スマホのOkuyukiを開き、写真へのアクセスを許可します。「選択した写真」だけでも利用できますが、許可した写真だけが対象です。
2. スマホの「Quest」タブで「Questとつなぐ」をオンにします。待機中は通知が表示されます。通知の停止操作、またはスイッチで待機を止められます。
3. QuestでOkuyuki Questを開き、表示されたGalaxyを選びます。見つからない場合はスマホに表示された `IPアドレス:ポート` を入力します。
4. Questとスマホに同じ4桁の番号が表示されたことを確認し、スマホで「許可」を押します。
5. Questの一覧で写真を選びます。「前へ」「次へ」で移動できます。ウィンドウの縦横比は写真に合わせます。
6. 終わるときはQuestアプリを閉じ、スマホの待機を停止します。Questの一時保存は停止時と次の起動時に削除します。

## つながらない場合
Wi-Fiの端末間通信禁止、ゲストネットワーク、VPNを確認してください。自動検出だけが動かない場合はIP入力を試してください。
スマホの待機が停止した／アドレスが変わった場合は、待機を再開しQuestの「再接続」を押すか、新しいアドレスで接続します。
写真がない場合はアクセス許可、3D写真の形式、スマホの一覧を確認してください。
Questに平面プレビューと表示される場合はOSを更新してください。SDKの立体描画が使えないOSでは平面にフォールバックします。
