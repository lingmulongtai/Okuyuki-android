# Okuyuki v0.1.0-alpha.11-preview

GalaxyとQuestの両方に、このプレビュー版をインストールしてください。長尺動画の共有・補正には両方の更新が必要です。対応OS、ダウンロード、更新、ペアリング、360°動画の共有と没入表示の手順は [実機テスト用ガイド](https://github.com/lingmulongtai/Okuyuki-android/blob/v0.1.0-alpha.11-preview/docs/DEVICE-PREVIEW.md) を参照してください。

起動時に更新を自動確認し、APKのハッシュ・署名・パッケージを検証してダウンロードします。インストールはOS上の確認が必要です。alpha.9以前からの更新は一度手動で行ってください。Questでのアプリ内インストールは実機未検証です。

## デザインの更新

LastWave Native の画面を参考に、角丸パネル、濃色を基調とした配色、淡い青灰色の操作部品を採用しました。Androidではライブラリ、Quest接続、設定と浮いたナビゲーションを再構成し、ライト／ダークと日本語／英語に対応します。Questの接続・ライブラリ・設定も同じデザインに統一しました。

## 試せること

- Galaxyのライブラリ、写真の権限状態、日本語・英語の切り替え、テーマと初回案内。
- ペアリングを承認したQuestへの3D写真、結合済み360°写真・MP4、DJI Osmo 360のLRF・OSVの共有。
- 対応するLRF・OSVのレンズ校正と、姿勢データからの実験的な回転平滑化。GalaxyおよびQuestのプレビューで切り替えられます。
- Questで360°動画を頭の向きに追従する没入表示で再生。対応するLRF・OSVには選択した回転平滑化も適用します。OSVは2本の映像から同じ表示時刻のフレームを組み合わせます。OSVの没入表示では、実験的な高画質モード（4096×2048）を選択できます。開始時に高画質を確保できない場合は標準画質を試します。

## 検証と制限

提供されたLRF・OSVに加え、50,001フレームの合成LRF・OSVの読み取りと合成姿勢情報のQuestへの転送、180,001フレームの合成姿勢データの符号化・補正・シークをテストし、投影シェーダーをデスクトップOpenGLで検証しました。**Galaxy・Quest実機での再生、シーク、接続、没入表示、頭部追従は未検証です** (`hardwareTested=false`)。OSVには2本の4K HEVC映像の同時デコードが必要なため、端末によっては再生できません。

回転平滑化は対応する姿勢情報を検証できたファイルに限ります。DJI純正補正と同等の結果は保証せず、移動によるぶれは対象外です。姿勢データは最大500,000フレーム（50 fpsで約2時間46分）・合計512 MiBまでです。撮影形式やメタデータの大きさによっては、より短い動画でも補正できない場合があります。時刻を照合できない場合は補正を無効にし、左右映像が同期できない場合は再生を停止します。共有中はGalaxyの元ファイルを編集・置換しないでください。360°写真の没入表示、TLSによる通信暗号化、ストア配信は未対応です。

ペアリング済みのQuestだけが共有にアクセスできますが通信はHTTPです。信頼できる自宅Wi-FiかGalaxyのテザリングで試してください。360°写真は64 MiB以下、動画は256 GiB以下のシーク可能なファイルが対象です。

署名付きAPK、SHA256SUMS.txt、署名検証結果、release-manifest.json、libheif／libde265のライセンスと対応ソースを配布します。提供された個人ファイルは含みません。
