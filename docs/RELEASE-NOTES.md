# Okuyuki v0.1.0-alpha.8-preview

GalaxyとQuestの両方に、このプレビュー版をインストールしてください。対応OS、ダウンロード、更新、ペアリング、360°動画の共有と没入表示の手順は [実機テスト用ガイド](https://github.com/lingmulongtai/Okuyuki-android/blob/v0.1.0-alpha.8-preview/docs/DEVICE-PREVIEW.md) を参照してください。

## 試せること

- Galaxyのライブラリ、写真の権限状態、日本語・英語の切り替え、テーマと初回案内。
- ペアリングを承認したQuestへの3D写真、結合済み360°写真・MP4、DJI Osmo 360のLRF・OSVの共有。
- 対応するLRF・OSVのレンズ校正と、姿勢データからの実験的な回転平滑化。GalaxyおよびQuestのプレビューで切り替えられます。
- Questで360°動画を頭の向きに追従する没入表示で再生。対応するLRF・OSVには選択した回転平滑化も適用します。OSVは2本の映像から同じ表示時刻のフレームを組み合わせます。

## 検証と制限

提供されたLRF・OSVの校正・姿勢読み取り、フレーム時刻の照合と姿勢計算を自動テストし、投影シェーダーをデスクトップOpenGLで検証しました。**Galaxy・Quest実機での再生、シーク、接続、没入表示、頭部追従は未検証です** (`hardwareTested=false`)。OSVには2本の4K HEVC映像の同時デコードが必要なため、端末によっては再生できません。

回転平滑化は対応する姿勢情報を検証できたファイルに限ります。DJI純正補正と同等の結果は保証せず、移動によるぶれは対象外です。時刻を照合できない場合は補正を無効にし、左右映像が同期できない場合は再生を停止します。共有中はGalaxyの元ファイルを編集・置換しないでください。360°写真の没入表示、TLSによる通信暗号化、ストア配信は未対応です。

ペアリング済みのQuestだけが共有にアクセスできますが通信はHTTPです。信頼できる自宅Wi-FiかGalaxyのテザリングで試してください。写真は64 MiB以下、動画は64 GiB以下のシーク可能なファイルが対象です。

署名付きAPK、SHA256SUMS.txt、署名検証結果、release-manifest.json、libheif／libde265のライセンスと対応ソースを配布します。提供された個人ファイルは含みません。
